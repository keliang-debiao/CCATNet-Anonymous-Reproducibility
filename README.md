CCAT-Net Anonymous Reproducibility Package

This repository contains the source code, experiment scripts, configuration files, documentation, tests, data-directory placeholders, log examples, and reference table files prepared for the anonymous reproducibility package of CCAT-Net.

Source Code

The src/ccatnet/ directory contains the core implementation of CCAT-Net and its supporting utilities.

model.py defines the CCAT-Net architecture, including the behavior semantic tokenizer, tabular encoder, country prototype adapter, balanced evidence retriever, behavior-regime mixture module, and prediction head.

train.py contains model training utilities, random-seed control, country encoding, class-weighted binary classification training, validation prediction, and threshold selection.

data.py contains dataset loading, target derivation, leakage-column screening, development/external feature harmonization, numeric and categorical preprocessing, and stratified fold construction.

metrics.py implements AUROC, AUPRC, F1, Brier score, expected calibration error, threshold selection, and fold-level metric aggregation.

config.py provides YAML configuration loading and output-directory utilities.

__init__.py defines the package metadata.

Configuration

The configs/ccatnet_so2024.yaml file contains the experiment configuration used by the scripts, including:

project seed and output directory;

development and external data paths;

label and country column candidates;

target-label matching rules;

leakage-screening keywords;

cross-validation and random-seed settings;

CCAT-Net model hyperparameters;

optimization settings;

evaluation settings; and

robustness-test configuration fields.

Experiment Scripts

The scripts/ directory contains the experiment and utility entry points.

00_make_synthetic_demo.py creates lightweight demonstration CSV files with the same general input structure expected by the pipeline.

01_prepare_data.py loads the development and external datasets, applies label filtering and leakage screening, harmonizes common features, and writes processed data files.

02_run_cv.py performs stratified cross-validation for CCAT-Net with fold-specific preprocessing and model training.

03_train_final_external.py prepares the development and external datasets with harmonized features and runs the external-evaluation pipeline.

04_ablation.py contains the reference-format table generation used for the ablation section.

05_robustness.py contains the reference-format table generation used for the robustness section.

06_make_tables.py copies the included reference metric CSV files into the experiment output structure used for table preparation.

07_run_all_demo.sh provides a single shell entry point for the demonstration workflow.

08_run_baselines.py implements baseline-model cross-validation for Logistic Regression, Random Forest, and HistGradientBoosting, with optional XGBoost, LightGBM, and CatBoost support when the corresponding packages are available.

Data Directories

The repository contains empty directory placeholders for data organization.

data/raw/ is reserved for the original input CSV files.

data/processed/ is reserved for processed datasets and demonstration data generated by the scripts.

Raw survey data are not included in this repository.

Evaluation and Reference Files

The results/ directory contains two components.

results/reference_metrics/ contains CSV files organized for the cross-validation, baseline, external-evaluation, published-context, ablation, robustness, statistical-comparison, and efficiency tables used by the project.

results/runs/ is the output location reserved for files generated by experiment execution.

The repository also includes results/reference_metrics/README.md, which documents the purpose of the reference table files.

Logs

The logs/ directory contains documentation for experiment logs and a set of example log files covering environment information, data auditing, cross-validation, external evaluation, and statistical processing.

Tests

The tests/test_smoke.py file contains lightweight smoke tests for:

metric computation;

preprocessing;

fold construction;

CCAT-Net model training; and

prediction-output shape checks.

Documentation

The docs/ directory contains supplementary repository documentation.

anonymous_review_notes.md describes the anonymization and repository-content conventions used for review.

reproducibility_checklist.md summarizes the repository workflow, expected file organization, leakage-control checks, and output locations.
